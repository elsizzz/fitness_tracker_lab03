# Система учета фитнес-тренировок (Fitness Tracker)

## Описание
MVP-приложение для персонального учета спортивной активности и тренировок (Лабораторная работа №3, Вариант 1, сложность **Well-done**).
Проект построен в объектно-ориентированной парадигме и включает:
* **Desktop GUI на PySide6**: таблица тренировок, поля ввода данных с валидацией, интерактивный график активности (`QtCharts`), панель логирования в реальном времени и главное меню.
* **Собственные исключения**: иерархия пользовательских классов ошибок (`FitnessAppError`, `InvalidDurationError`, `InvalidCaloriesError` и др.).
* **Единая БД в Docker**: хранение данных в PostgreSQL 16 (с автоматическим резервным откатом на SQLite при отсутствии запущенного Docker-демона).
* **Веб-версия на FastAPI**: синхронизированный веб-интерфейс с таблицей, графиком `Chart.js` и REST API.
* **Автотесты `pytest`**: проверка доменной логики, исключений, БД и веб-эндпоинтов.

## Инструкции по запуску

### 1. Установка зависимостей
Создайте и активируйте виртуальное окружение, затем установите пакеты:
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Запуск базы данных PostgreSQL в Docker
```bash
docker compose up -d
```

### 3. Запуск графического интерфейса (PySide6 Desktop)
```bash
python main_gui.py
```

### 4. Запуск веб-версии приложения (FastAPI)
```bash
python main_web.py
```
После запуска откройте в браузере:
* Веб-интерфейс: `http://127.0.0.1:8000/`
* Документация Swagger UI: `http://127.0.0.1:8000/docs`

### 5. Запуск тестов `pytest`
```bash
pytest -v
```

## Краткая справка
1. **Добавление тренировки**: выберите дату в календаре, укажите вид активности, введите длительность (от 1 до 1440 минут) и количество сожженных калорий (от 1 до 20000 ккал), после чего нажмите **«Добавить тренировку»**.
2. **Генерация демо-данных**: для быстрой проверки построения графиков выберите в верхнем меню `Файл -> Загрузить демо-данные`.
3. **Удаление записи**: выделите нужную строку в таблице тренировок и нажмите кнопку **«Удалить выбранную»**.
4. **Контроль ошибок**: при вводе некорректных значений срабатывают собственные исключения приложения, выводится предупреждение, а деталь ошибки фиксируется в нижнем окне **«Лог активности системы»**.
